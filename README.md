# SGU - 841047 - Software Engineering

Lecture slides for the Software Engineering course at Saigon University.

`slides/` contains nine English-language PDF chapters covering software engineering fundamentals, development processes, project management, requirements, modeling, architecture, implementation, testing, and evolution.

## Working with the slides

Open a chapter link above to view its PDF on GitHub, or download the file to read it locally. Use **Code → Download ZIP** to download all course materials together.

The chapter numbers follow the order of the course materials. The repository currently contains lecture slides; exercises, project source code, and reports can be added as the course progresses.
