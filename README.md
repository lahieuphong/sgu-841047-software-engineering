## Working with the materials

Open the chapter links to view PDFs on GitHub, or download the original Word reports for local reading. Each coursework index links to its submissions and supporting files. Use **Code → Download ZIP** to download the published collection.

Assignment, homework, and lab identifiers follow the original submissions. The two BT2 reports cover different subjects and remain in separate directories. Original report filenames and contents are preserved; external image filenames use portable English names and retain their figure numbers.

Lab 1 through Lab 6 develop the flight-ticket-booking project. The project README connects those labs to the midterm reports, diagram sources, and application snapshot. Lab 5 and the first midterm submission share the same report body and embedded images, with different cover titles; both remain available as separate submissions.

## Source snapshot

The application snapshot uses React, Express, and MySQL. Its current frontend lists flights, while the project report documents a broader application and links to a separate source repository and a Canva presentation. See [project/README.md](project/README.md) for provenance and known differences.

Local dependencies, private environment configuration, nested Git metadata, operating-system files, and import backups are excluded from publication. The backend configuration template is [project/source/backend/.env.example](project/source/backend/.env.example).
